Jarvis: Personal AI Assistant

A self-hosted assistant I control from Telegram or by voice. Say “Hey Jarvis” and it answers out loud, reads my mail and calendar, and runs safe actions on my PC.

Telegram / Voice→n8n agent→Gemini → Ollama→Tools

Job Application Assistant

Forward a job link or text to a private Telegram bot. It reads the posting, scores the fit against my resume, flags scam risks, and drafts the application only after I approve.

Hobby project spotlight: LipiRx

A personal project I built for learning and as a hobby, to explore Kotlin Multiplatform and multi-agent AI. It is designed for retail pharmacies in Bangladesh: point the camera at a doctor’s prescription and a supervisor agent coordinates specialist agents that read it, fill in the details and audit it for safety.

Personal projectKotlin MultiplatformCompose MultiplatformMulti-agent AIVision AIOn-device AILiteRT-LMGeminiGroqOpenAIOllama
View on GitHub
  • Supervisor-driven agents. A manager AI decides which specialist runs next (OCR, parser, brand matcher, safety auditor) and falls back to rules, with guardrails against finishing too early, if the model is unavailable.
  • Brand names. Finds each medicine written on the prescription.
  • Generic compositions. Matches each brand to its active ingredient.
  • Local dosage schedules. Understands the dosing notation used locally.
  • Tablet quantities. Calculates how many tablets to hand over.
  • Similar brands. Suggests alternative brands for each medicine.
  • Needs review flags. Marks unclear items so the pharmacist confirms before dispensing.
  • Zoom and pan. Inspect the original photo next to the result.
  • Safety audit. Checks dosage safety, interaction risks and unreadable spellings before anything reaches the pharmacist.
  • Your choice of AI provider, per agent. Gemini, Groq, OpenAI, any OpenAI-compatible endpoint such as a local Ollama server, or an on-device model, assigned agent by agent.
  • Works offline. An on-device small language model (Google LiteRT-LM) can run the agents. Pick Hybrid fallback (default), On-device first, On-device only or Cloud only.
  • Scan history. Past scans are saved on the device, with delete and clear all.
